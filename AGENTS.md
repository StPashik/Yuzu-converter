# Yuzu Converter

Общаться по-русски. Нативное приложение macOS 13+, новый код с нуля. Старые checkouts, их исходники, историю и caches не менять и не переносить. Исключение по прямому запросу владельца: иконка приложения и menu bar из Yuzu Mac App. Proprietary ресурсы и binaries Tangerine не копировать. Исследовательские отчёты можно читать как reference, отделяя наблюдения от предположений.

Обязательны docs/Requirements.md и принятый план docs/Architecture.md. Конвертация и шесть Actions входят в объём; File tools не добавлять. Не подгонять требования под доступный backend, отмечать ограничения в docs/Conversion-matrix.md.

GitFlow: feature/* от develop, независимый QA, merge --no-ff; main и tags только для выпуска. Текущий запрос владельца разрешает публикацию в StPashik/Yuzu-converter. Force push запрещён.

Автотесты в отдельных scratch paths. Новые ручные проверки отложены, физические Finder/Sandbox gates отмечать непроверенными. Не запускать параллельные Swift builds в одном scratch. Код понятный, комментарии объясняют причины решений. Перед выпуском сверить фактические проверки, лицензии, checksum и ограничения.
